# Changes

## 2.2.0
- Insights tab: "Today on the farm", a daily suggestion that changes each morning (weather warnings, monthly jobs for the species on the farm, farm-data checks, general tips), plus "Also worth doing".
- Tree distribution by species and type, trees per hectare, young trees, spacing check, colour-by-species view with legend.
- Rain & water: last 7/30/90 days, days since rain, 7-day forecast, 30-day water balance, monthly rainfall chart, rain on each pond.
- Shared to-do list (data format v3; older farms upgrade automatically).

## 2.1.1
- Clear message instead of endless "Connecting…" when the database can't be reached.
- Each publish stamps file links with its version, so browsers never mix old and new files.

## 2.1.0
- No accounts: the farm is shared with a private family link. Anyone with the link can view and edit, live.
- "Your name" (optional) shows who changed what.
- Backups can only be removed once they're over 30 days old.

## 2.0.0
- Shared family farm: email/password sign-in with email confirmation, live sync between devices, owner manages family access.
- Automatic daily backups, plus one before every import, restore or clear, with one-click restore.
- Test version at `/beta/` on a separate test farm.
- Automatic checks before every publish. Older farm files upgrade automatically.
- Added common Indian farm species (Teak, Areca nut, Jackfruit, Sapota, Silver oak, Sandalwood…).
- Works on phones.

## 1.0.0
- Single-file 3D editor: houses, sheds, trees, ponds, garden beds, paths; live weather; seasons.
